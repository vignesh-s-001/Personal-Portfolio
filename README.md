# Creative Developer Portfolio

An immersive, highly interactive personal portfolio built using React, Vite, and GSAP (GreenSock Animation Platform) featuring procedural canvas lightning effects, floating tech stack bubbles, custom draggable physics, and glassmorphism styling.

## Getting Started

To run this project locally, follow these steps:

### 1. Install Dependencies
Make sure you have [Node.js](https://nodejs.org/) installed, then run the following command in your terminal:
```bash
npm install
```

### 2. Run the Development Server
Start the local server with Vite:
```bash
npm run dev
```

The server will typically start at [http://localhost:5173](http://localhost:5173). Open this link in your browser to view the application with hot module replacement (HMR) enabled.

### 3. Build for Production
To build the application for production deployment:
```bash
npm run build
```

The production assets will be built into the `dist/` directory.

### 4. Preview Production Build
To preview the generated production build locally:
```bash
npm run preview
```

## Technologies Used
* **React**
* **Vite**
* **GSAP** (for high-performance animations and custom draggable components)
* **HTML5 Canvas** (for lightning render loop)
